# אתר קורות החיים של ליטל רוטר

## מה יש בתיקייה

| קובץ | תפקיד |
|---|---|
| `index.html` | תוכן העמוד – כל הטקסט של קורות החיים נמצא כאן |
| `style.css` | העיצוב (צבעים, גופנים, פריסה, וגם עיצוב ה-PDF) |
| `assets/profile.jpg` | תמונת הפרופיל (ריבועית, 640×640) |
| `Lital-Rotter-CV.pdf` | הקובץ שיורד בלחיצה על "הורדת קורות חיים (PDF)" |
| `build-pdf.bat` | מייצר מחדש את ה-PDF מתוך `index.html` |
| `assets/qr.png`, `assets/qr.svg` | קוד ה-QR (נוסף אחרי שהאתר עלה לאוויר) |

## איך מעדכנים את קורות החיים

1. פותחים את `index.html` ב-Notepad (קליק ימני ← "פתח באמצעות") ומשנים את הטקסט הרצוי.
   כל משרה היא בלוק `<div class="item">`; כדי להוסיף משרה מעתיקים בלוק קיים ומשנים את התוכן.
2. לחיצה כפולה על `build-pdf.bat` – ה-PDF נוצר מחדש מאותו תוכן, כך שהאתר וה-PDF תמיד זהים.
3. פותחים את `index.html` ואת ה-PDF במחשב ובודקים שהכול נראה תקין (ושה-PDF נשאר בעמוד אחד).
4. מעלים ל-GitHub: בעמוד ה-repository לוחצים **Add file ← Upload files**, גוררים את
   `index.html` ואת `Lital-Rotter-CV.pdf`, ולוחצים **Commit changes**.
5. אחרי דקה-שתיים האתר מתעדכן. אם עדיין רואים גרסה ישנה – לרענן עם Ctrl+F5.

## מה לא משתנה

- **כתובת האתר וקוד ה-QR נשארים קבועים.** אין צורך להדפיס QR חדש אחרי עדכון תוכן.
- ה-QR יפסיק לעבוד רק אם משנים את שם המשתמש ב-GitHub, את שם ה-repository, או מוחקים אותו.

## שינויים נפוצים

- **החלפת תמונה:** לשמור תמונה ריבועית בשם `profile.jpg` בתיקיית `assets` במקום הקיימת, ולהעלות אותה ל-GitHub לתוך `assets`.
- **שינוי קישור LinkedIn / מייל / טלפון:** לחפש את הערך הישן ב-`index.html` ולהחליף (המייל והטלפון מופיעים פעמיים: בכפתור ובשורת ה-PDF).
- **שינוי צבעים:** בראש `style.css`, תחת `:root`.
